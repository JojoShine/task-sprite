# Task Sprite

独立运行的像素桌面任务伙伴。Tauri 2 + React + TypeScript + Rust + SQLite，无需账号、后台服务或 FlowCraft。

暖白像素便笺，内置橘猫、柴犬、机器人、小幽灵；支持本地任务新增、编辑、完成与恢复、直接删除、当前专注、延期显示、每日汇总、稍后提醒、免打扰与全属性 CSV 导出。

## macOS 使用

可直接打开：`release/Task Sprite.app`。原始构建产物位于 `src-tauri/target/release/bundle/macos/Task Sprite.app`。双击启动；单击精灵互动，双击精灵或点击头顶卡片，根据精灵位置在上方、侧边或下方的可用区域展开任务面板；展开时卡片隐藏，收起面板后恢复。待办／逾期数量位于精灵脚下的像素底座。拖动精灵可移动；macOS 不显示程序坞图标；左键点击顶部黑白精灵图标，优先在图标下方打开面板，若会挡住精灵则自动避让，右键可显示／隐藏精灵或退出。关闭面板不退出应用。

首次进入「提醒设置」点击「发送一条测试提醒」，允许系统通知。macOS 端使用 UserNotifications 原生接口检查授权及提交结果，系统专注模式、横幅设置仍可能影响实际展示。未授权或提交失败时保留待提醒记录，任务气泡继续可用。应用退出后停止调度；重新启动只补当天汇总。

本地构建采用完整 ad-hoc 签名以绑定应用身份；暂未使用 Developer ID 签名和公证，尚不是公开发行包。Windows 构建入口保留，但未在 Windows 实机验证；macOS 多显示器和 Spaces 行为需按实际设备进一步验收。

## 数据与备份

任务卡片右上角的垃圾桶直接删除该任务，待办与已完成任务均支持；同步清理关联的稍后提醒、截止提醒记录和当前任务标记，数量与CSV导出立即更新。删除不设回收或恢复入口。

数据文件：`~/Library/Application Support/io.jojoshine.tasksprite/tasks.sqlite3`。

任务、角色、窗口位置、提醒偏好和通知去重均写入 SQLite。备份前退出应用，复制整个上述目录；恢复时同样先退出应用。升级不删除数据，遇到高于本应用版本的数据结构会拒绝打开；执行数据库迁移前保留备份。

设置中的「导出全部任务 CSV」会打开保存对话框，导出待办和已完成任务的12列：任务ID、标题、说明、优先级、状态、创建时间、更新时间、计划完成日期、计划完成时段、计划完成时间、实际完成时间、是否当前任务。创建、更新与实际完成时间使用本地时间并注明时区；中文文件采用UTF-8 BOM，保留换行与引号，公式样式文本按普通文字导出。取消保存不会修改数据。CSV适合查阅，不是完整数据库备份。

设置中可查看与复制持久化的本地用户编号，用于未来微信关联；该编号不是登录凭据。实际扫码绑定和云端同步尚未接入，后续方案见[微信关联规划](docs/specs/wechat-binding-roadmap.md)。

首版不包含云同步、小程序、AI、养成、自动操作电脑或 Agent/Harness 接入。

## 开发

要求 Node.js 22.12+、Rust 稳定版与 Xcode。此次使用项目内 `.tooling` Rust 工具链，未修改 shell 配置。

```sh
npm ci --registry=https://registry.npmjs.org
export CARGO_HOME="$PWD/.tooling/cargo"
export RUSTUP_HOME="$PWD/.tooling/rustup"
export PATH="$CARGO_HOME/bin:$PATH"
npm run desktop
```

如果使用自行安装的全局 Rust，可省略这三个环境变量。

```sh
npm test
npm run build
cargo test --manifest-path src-tauri/Cargo.toml
npm run bundle
```

## 动作与任务录入

任务只需一段文本，编辑框随内容自动增高，短任务保持紧凑；点击截止时间直接选择「周几＋上午／下午」；上午截止12:00、下午截止17:00。选择范围从当前时段到七个日历天后的同一时段；17:00及以后从次日上午到七天后的上午。周一作为每周起点，所有下周日期统一带「下周」前缀，「今天／明天」优先显示。可以不设截止时间，已有日期任务保留原值。优先级直接点击「高／中／低」。

半天截止时间会参与同日逾期判断及到点提醒。提醒被免打扰或权限阻止时不计为送达；系统确认提交后按任务和截止时段去重。应用退出后不运行提醒，次日仍通过每日汇总关注旧逾期任务。已有标题与补充说明会合并显示，保存时保留全文。

待机时每隔约12–28秒随机做一次短暂小动作，避免连续重复；单击精灵会有摸摸头等回应，双击或点击气泡打开任务面板。提醒、庆祝和免打扰休息优先于随机动作，窗口隐藏时暂停。

面板底部点击「试试动作」，可分别预览待机、提醒、庆祝、休息，5秒后恢复；预览不会修改任务或发送通知。自然触发：完成任务庆祝4秒；提醒提交成功后进入提醒态10秒；配置的免打扰时段进入休息态。启用「减少动态效果」或系统减少动态效果时，以静态姿势为主。

## 外观与轻量交互

外观默认跟随系统，可在设置中直接选择「跟随系统／浅色／深色」，立即保存并同步到精灵气泡和任务面板。空任务页固定显示；空间不足时收起插画或重复提示，新增入口仍保留。任务列表默认每页三条，用左右箭头翻页；极小窗口或提示区占用空间时自动减少当页条数，列表不滚动。设置与编辑页保留必要滚动。

没有当前任务时，多条待办会在精灵上方叠成便笺，最多显示三层纸张，通过左右按钮查看并显示当前序号；点击正文打开任务面板。平时不会自动翻页；新任务逾期或逾期任务恢复时，会回到优先展示的逾期任务。气泡明确显示「逾期提醒」和逾期状态，逾期任务优先于未来的专注任务。已完成任务不加入叠层。设为当前后，头顶改为一张当前任务卡片，支持直接完成，卡片内保留红色逾期提示；点击展开面板后，卡片与气泡均隐藏，收起后恢复。截止时间在独立页面选择，先选周几，再点上午或下午返回表单；返回或Esc取消，任务草稿保留。

最近的窗口与屏幕边界检查见[可见性检查记录](docs/visibility-checks-2026-11-13.md)。分页紧跟当页卡片，默认间距10px；卡片随空间在紧凑和舒展高度间适配。

桌宠、任务面板和菜单栏展开面板可使用显示器完整工作区，不额外预留右侧间距。系统通知横幅位置由macOS控制。通知所用应用图标已统一为黑白像素幽灵，源文件为`assets/app-icon.svg`；可用`npm run tauri -- icon assets/app-icon.svg`重新生成平台图标。

展开面板时先检查精灵和底座的可见区域，优先上方，其次空间更足的侧边，再考虑下方，保持至少12逻辑像素间隔。小屏幕中央四边都不够时，精灵会小幅横向让位，避免强行把面板压在精灵上；同一位置重复展开保持稳定。收起面板后恢复卡片的规则继续生效。
