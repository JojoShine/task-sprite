# Task Sprite macOS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Run the standalone Tauri desktop companion on macOS with four pixel characters, persistent local tasks and reminders.
**Architecture:** React renders two local windows; narrow Rust commands own SQLite, preferences and reminders. No account, backend, FlowCraft or model dependency.
**Tech Stack:** Tauri 2, React, TypeScript, Vite, rusqlite, chrono, Vitest, Rust tests, original PNG assets.
**Spec:** ../specs/2026-11-13-standalone-design.md. User explicitly authorized plan creation and immediate inline development.

## Global Constraints
- Third selected visual; four switchable pets; 80–100px character; roughly 360×520 panel.
- Local SQLite is source of truth; preserve data across restarts; no task deletion, cloud, AI or autostart in this delivery.
- Summary 09:00, quiet 23:00–08:00, snooze 30/120 minutes, persistent daily deduplication.
- Native menus restore windows; panel close hides; explicit quit exits; coordinates remain on visible monitors.
- Stable app identifier io.jojoshine.tasksprite. No arbitrary SQL or shell exposed to renderer.
- macOS verified here; Windows remains unverified until native testing.

## Review Focus
- Empty/invalid titles, priority and date input must never corrupt the database (Task 2).
- Reopen/restart must retain preferences, tasks and reminder history (Tasks 2–3).
- Completion and snooze changes must cancel outdated notifications (Task 3).
- Small/removed monitors and pixel scaling must keep windows accessible (Task 4).
- Save failure or panel blur must preserve unsaved input (Task 5).
