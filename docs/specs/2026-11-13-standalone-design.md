# Task Sprite 独立桌面任务精灵设计

日期：2026-11-13
状态：用户已审阅并授权直接实施；macOS 本地预览已实现，验收结果见 ../progress.md。

## 定位与交付目标

面向个人的独立桌面任务伙伴，以像素角色和轻量任务便笺帮助使用者记录任务、关注当前重点、发现延期并完成工作。首版独立安装、本地维护，无需注册或运行其他服务。

已确认方向：Tauri；macOS 优先，同时考虑 Windows；第三版复古像素便笺风格；橘猫、柴犬、机器人、小幽灵四款可随时切换；保留本地任务与提醒。小程序、FlowCraft 数据接入、AI Agent 与 Harness 集成均不在本次范围。

本文件取代先前在 FlowCraft 仓库中围绕 Electron、服务端账号、任务同步及三端联动的首版实现设想。既有讨论仅作为历史资料，不再作为本项目开发约束。

## 技术选择

| 部分 | 选择与职责 |
| --- | --- |
| 桌面壳 | Tauri 2，管理窗口、托盘、系统通知与生命周期 |
| 界面 | React、TypeScript、Vite，独立的像素便笺界面 |
| 本地业务 | Rust 受限命令，负责任务持久化、提醒调度与窗口边界 |
| 任务数据 | SQLite，使用 rusqlite 的 bundled SQLite；通过 Rust 命令访问，界面不接受任意 SQL |
| 偏好 | SQLite 内独立 settings 记录，保存角色、位置、提醒偏好和当前专注任务，避免再引入第二种持久化机制 |
| 角色动画 | 原创透明 PNG 逐帧素材，CSS steps 与 pixelated 显示；减少动态效果时静态显示 |
| 提醒 | Rust 运行期调度与 Tauri 通知能力；面板隐藏时继续，退出后停止 |
| 验证 | Vitest 验证界面关键操作，cargo test 验证日期、持久化、提醒和窗口布局规则 |

采用相互兼容的稳定依赖并锁定版本，不机械使用当天最新插件。实施时已配置项目内 Rust 1.100 工具链，并使用 Xcode 26.6 完成 macOS arm64 构建。

## 第一版界面

### 精灵与面板

精灵与任务面板为两个有界窗口。精灵本体约 80–100 逻辑像素，可拖动，默认位于主屏右下。精灵旁显示当前任务和逾期数量，用户可隐藏提示条。点击展开面板，拖动不触发点击。

任务面板约 360×520，在精灵旁自动选择可用位置，小屏可滚动。默认展示当前专注任务与少量紧急任务，提供全部待办入口。已完成任务可在面板内查看并恢复为待办。

窗口默认置顶；精灵展示不抢键盘焦点，点击面板后可正常输入。macOS 跨 Spaces 与全屏空间需实测，锁屏与系统安全界面不保证覆盖。显示器断开、缩放变化后窗口回到可见工作区。菜单栏／托盘提供显示、隐藏和退出入口；关闭面板仅隐藏，明确退出才终止应用。开机启动第一版不默认开启，可后续增加设置。

面板中的未保存输入不能因失焦丢失。透明窗口保持紧凑，不铺满屏幕，不在大片透明区域拦截其他应用的点击。

### 视觉与角色

视觉目标：[已选第三版效果图](../../assets/desktop-companion-selected.png)。暖白便笺、暖灰文字、苔绿色操作、砖红色逾期提示与克制的像素边角。任务文字保持系统字体，像素效果用于角色和局部装饰。

四角色在面板底部提供预览，随时切换并保存，重启后恢复。每款角色具备待机、提醒、完成庆祝、休息四态。素材原创，不从参考图直接裁切，不依赖远程素材服务。

状态由任务日期、用户选择和完成操作触发，不能由“选中任务”推断用户实际在工作。动画只表达状态，不决定提醒规则，也不采集屏幕或应用活动。

## 本地任务

任务字段：id、title、description、priority（high/med/low）、status（todo/completed）、dueDate（可空 YYYY-MM-DD）、createdAt、updatedAt、completedAt（可空）。首版不要求项目归属，不引入账号、负责人、协作、阶段、附件或产物模型。

- 新增任务只需标题，默认中优先级、待办，无日期。
- 可编辑标题、描述、优先级与截止日；可清除截止日、标记完成与恢复待办。完成时设置 completedAt，恢复时清除。
- 首版不提供删除，避免为轻量初版加入回收站和恢复机制；完成任务可以归档查看。
- 可把一项待办设为当前专注。完成该任务后清空专注选择，不自动替用户开始下一项。
- 按逾期、今天到期、未来截止日、无日期分组；组内优先级、截止日、创建时间和 ID 稳定排序。完成任务单独呈现。
- 日期以使用者本地日历“今天”比较，截止日当天不算延期，次日开始计逾期。日差按日历日期计算，覆盖跨月、闰日与夏令时。
- 保存成功后再显示成功状态；数据库失败保留输入并展示可理解的错误，不把内存修改当作已经落盘。

## 数据持久化与备份

SQLite 为任务与偏好的真值来源。任务变更和相关专注／提醒状态更新使用事务；迁移按版本前进，启动时不得通过删库解决版本不兼容。安装更新与退出保留本地数据。

首版文档说明系统应用数据目录的位置，以及退出应用后备份整个数据目录的方法。迁移前保留可恢复的数据备份，迁移失败不覆盖原数据。本轮不增加导入导出界面、云备份或自动同步。

## 本地提醒

- 默认每天本地 09:00 汇总今天到期和已逾期任务；23:00–08:00 免打扰；支持调整汇总时间、免打扰区间和关闭通知。提醒无到期任务则不发送。
- 每分钟检查，并在任务变更、恢复运行、唤醒和跨日时重新计算；数据库持久记录每日汇总去重。初次启动已过汇总时间可补当天一条，休眠后不连续补发历史提醒。
- 待办可设置30分钟或2小时后提醒，保存绝对时间。触发时任务已完成则取消；落在免打扰期间顺延；同批到期合并。
- 精灵提示中的延期数量独立于系统通知权限。权限拒绝仍能查看面板和提示，通知点击打开面板，不依赖平台通知操作按钮一致性。
- 提醒仅在应用运行时执行。关闭面板不影响调度；明确退出后停止，下一次启动恢复当天状态。
- 通知和动画根据确定的任务规则触发，不调用模型。

首个交付先验证纯本地任务、角色和提醒的独立工作能力。本轮不要求配置模型密钥，不引入云端服务。长期定位保留按需 AI 排序与推进建议，但接入方式、用户授权与密钥存储在后续阶段单独设计；不把尚未接入的能力显示成可用按钮。

5. 验证退出后备份及迁移失败恢复；测量常驻 CPU／内存；完成 macOS 本地构建与安装测试，记录 Windows 未验证项目，不承诺未经实测的耗电指标。

测试重点：本地无后端可用、数据库迁移不丢数据、失焦不丢输入、账号和网络完全不成为前提、睡眠后提醒不轰炸、已完成任务不继续提醒。
